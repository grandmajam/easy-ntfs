# Easy NTFS

Read and write NTFS drives on Mac. Use your Windows drive in Finder. Copy, edit and move files without reformatting.

Easy NTFS also shows your volumes and free space, mounts, unmounts and safely ejects drives, checks NTFS volumes, and formats and partitions external drives.

This repository hosts Easy NTFS releases and the public issue tracker. The app's source code is not published here.

## Requirements

- A Mac with Apple Silicon. Intel Macs are not supported.
- macOS 15.6 or later.

## Download

Download Easy NTFS from https://easy-ntfs.com/download. Each release is also published on the [Releases](https://github.com/grandmajam/easy-ntfs/releases) page of this repository.

Move Easy NTFS to Applications and open it. The app guides you through enabling its extension and approving the permissions your Mac needs. The [installation guide](https://easy-ntfs.com/support#installation) covers the steps.
